
# TryHackMe Writeups 🔐

Personal writeups and walkthroughs documenting rooms completed on [TryHackMe](https://tryhackme.com), as part of my hands-on
cybersecurity learning journey — with a focus on penetration testing, Active Directory, and Linux/Windows fundamentals.

> ⚠️ **Disclaimer:** These writeups are for educational purposes only, documenting my personal learning process.
Techniques described here should only be used on systems you own or are authorized to test.

## 📌 About

I'm a B.Tech CSE student focused on cybersecurity, working through TryHackMe's learning paths as part of my prep for a career in penetration testing.
This repo tracks my progress room-by-room — methodology, tools used, and key takeaways from each challenge.


## 📝 Writeup Template

Each writeup follows a consistent format:

```markdown
# Room Name

**Difficulty:** Easy / Medium / Hard
**Category:** e.g. Linux, Windows, Web, Active Directory
**Link:** [TryHackMe Room](https://tryhackme.com/room/xxxx)

## Overview
Brief summary of what the room covers and what skills it tests.

## Enumeration
Tools and techniques used to gather information (nmap, gobuster, etc.)

## Exploitation
Steps taken to gain access / solve the challenge.

## Privilege Escalation
(If applicable) How root/admin access was achieved.

## Key Takeaways
What I learned — new tools, concepts, or techniques.

## Flags
- User flag: `THM{...}`
- Root flag: `THM{...}`
```
