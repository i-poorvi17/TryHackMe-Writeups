# TryHackMe - Pre Security Pathway (Completed)

## Overview
The Pre Security path is TryHackMe's foundational learning track, covering the core building blocks needed before moving into offensive or defensive security specializations.

## Modules Covered
1. **Introduction to Cyber Security** — overview of the field, career paths, and mindset
2. **Network Fundamentals** — OSI model, TCP/IP, how data moves across networks
3. **How the Web Works** — HTTP/HTTPS, client-server architecture, cookies, requests
4. **Linux Fundamentals** — file system, permissions, basic commands, navigating the terminal
5. **Windows Fundamentals** — OS structure, basic administration, security controls

## Key Takeaways
- Solid grounding in how networks, the web, and operating systems function — the foundation every security specialization builds on
- Comfortable navigating both Linux and Windows environments at a basic level
- Understood the difference between offensive and defensive security roles, which helped shape my direction toward penetration testing
