# TryHackMe Writeups

## About TryHackMe
[TryHackMe](https://tryhackme.com) is a hands-on cybersecurity learning platform that teaches concepts through gamified, browser-based labs called "rooms." Instead of pure theory, it lets learners practice real skills — Linux, networking, web exploitation, digital forensics, and more — in safe, guided virtual environments. It's widely used by beginners and professionals alike to build practical, job-relevant security skills.

This repository contains my personal notes and writeups from TryHackMe rooms, documented as part of my ongoing journey into cybersecurity — with a focus on penetration testing and offensive security.
